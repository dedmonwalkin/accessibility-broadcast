# Remote Setup

This repository is configured with:

- `origin`: `git@github.com:sandrockwalsh/accessibility-broadcast.git`

## Verify remote

```bash
git remote -v
```

## Push current history

```bash
git push -u origin main
```

## If the GitHub repo does not exist yet

Create it first (name: `accessibility-broadcast`), then run:

```bash
git push -u origin main
```

## Change remote URL later

```bash
git remote set-url origin <YOUR_GITHUB_REMOTE_URL>
```
